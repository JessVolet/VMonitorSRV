# Code Style & Guidelines

1. **Language:** All code (variables, functions, classes, etc.) and commit messages MUST be written in English.
2. **Debuggability:** The code must be easily debuggable. Ensure proper error handling, logging, and clear states.
3. **Comments:** Keep comments to a minimum. Use vague technical comments only if absolutely necessary to explain complex logic that isn't self-evident. Code should be self-documenting.
4. **Formatting:** Code must always be properly formatted according to the standard project formatters (`qmlfmt`, `gofmt`, etc.).
5. **Structure:** Maintain a production-ready codebase with clean structure, logical separation of concerns, and modularity.
